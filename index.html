Connect to Google Sheets — One-time setup
This app uses your Google Sheet as the database. All entries are stored and synced live. Follow the steps below to connect:
1
Go to Google Cloud Console → Create a project → Enable Google Sheets API and Google Drive API.
2
Go to APIs & Services → Credentials → Create OAuth 2.0 Client ID (Web application). Add your file's origin to Authorised JavaScript origins (e.g. http://localhost or file:// or your GitHub Pages URL).
3
Copy your Client ID and paste it below. The Sheet ID is pre-filled from your link.
4
Make sure your Google Sheet is shared with your Google account (or set to "Anyone with the link can edit" for simpler setup).
